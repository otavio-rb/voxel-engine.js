A Ponte: Main Thread & VoxelEngineThe Bridge: Main Thread & VoxelEngine

Fachada da main thread: dona do canvas e do input do DOM, encaminha os dois para o engine worker, onde o mundo é simulado e renderizado de fato. Não registra conteúdo (blocos, geradores, entidades) — isso acontece dentro dos workers, capítulos adiante.Main-thread facade: owns the canvas and DOM input, forwards them to the engine worker, where the world is actually simulated and rendered. It does not register content (blocks, generators, entities) — that happens inside the workers, later chapters.

Por que transferir o canvas?Why transfer the canvas?

O construtor recebe só { canvas, worker } e chama canvas.transferControlToOffscreen() imediatamente — a partir daí o desenho é todo responsabilidade do worker, e a main thread fica livre para o DOM nunca travar o frame. O worker é criado no call site do seu app, não dentro da engine, para o bundler conseguir localizar o arquivo do worker.The constructor takes only { canvas, worker } and calls canvas.transferControlToOffscreen() immediately — from that point on, drawing is entirely the worker's responsibility, and the main thread stays free so the DOM never stalls a frame. The worker is created at your app's call site, not inside the engine, so the bundler can find the worker file.
